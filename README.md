# VOICE MATE

VOICE MATE 4 홍보 및 아카이브 사이트 샘플입니다.

## GitHub Pages 배포

1. GitHub에서 새 Repository를 생성합니다.
2. 이 폴더의 `index.html`을 Repository 루트에 업로드합니다.
3. Repository의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, Folder는 `/ (root)`로 선택하고 저장합니다.
6. 잠시 후 GitHub Pages 주소에서 사이트를 확인할 수 있습니다.

현재 4회차 자료를 기반으로 제작되어 있으며, 이후 1~3회차 및 추가 참가자 정보를 같은 구조로 확장할 수 있습니다.
